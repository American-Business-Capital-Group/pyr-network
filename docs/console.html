K1 — One Memory

One Memory is one shared memory store across models and services. As built in the pilot, a single SQLite memory is shared by the command-line tools, the demo, and the Ignis HTTP service, so what one surface learns is available to the others. Failed-output write-back is quarantined — output that fails verification is not written into the shared memory.

What Ignis does

Models and agent engines are interchangeable parts unless something underneath decides which one should answer, remembers what has already happened, and carries that context to the next step. That underneath is Ignis — the Pyr Neural Network layer. Three of Prometheon's key concepts are implemented here:

K5 — Intent Routing

Each prompt is semantically classified and routed to the model type, vendor, and model that fit it, instead of a fixed default. Routing respects lifecycle: only Approved models serve, and lifecycle state is enforced at routing time.

K1 — One Memory

One shared memory across models and services, instead of each tool keeping its own silo. In the pilot, a single SQLite memory is shared by the command-line tools, the demo, and the HTTP service — demonstrated live, across models.

K3 — Context That Travels

Context moves with the work: when a task is routed to a different model or handed to another platform, the relevant context travels with it rather than being re-explained or lost at the boundary.

Live today

Ignis is not a roadmap item. It runs as a live HTTP service on the pilot host, and the Prometheon SI gateway answers Ignis-platform chats through that service. The console on this site talks to the same gateway with the same accounts as prometheon.si, locked to the Ignis platform, and its Routing & Memory panel reads the live catalog counts from the gateway — model types, vendors, and Approved models — rather than quoting static numbers.

What One Memory means here, exactly: the pilot demonstrated one shared memory store used across models and across the CLI, demo, and HTTP service surfaces. That is the claim — a shared, working memory layer — stated at the scope it was demonstrated.

One platform, several doors

Ignis is one of the platforms of Prometheon SI, and the layer the others run on: it routes for Prometheon SI and for Lampas, the recursive engine. The other doors: Prometheon SI (the unified app), Lampas SI by Pyr Neural Network, and AI Civilization and Legacy Agents SI inside the Prometheon SI chat.
